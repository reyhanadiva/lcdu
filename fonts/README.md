# Font (di-host sendiri)

File woff2 variabel dari Google Fonts, dipotong per subset (Latin / Arab). Semua berlisensi SIL Open Font License 1.1 —
teks lisensi lengkap di `LICENSES.txt`. `@font-face` ada di `<style>` paling atas `index.html`.

| File | Keluarga | Berat | Dipakai untuk |
|---|---|---|---|
| fraunces-latin.woff2 | Fraunces | 300–700 | judul (`--f-display`), di-preload |
| fraunces-italic-latin.woff2 | Fraunces Italic | 600–700 | "Online." / "Nirlaba." di Pengantar (tidak di-preload) |
| plus-jakarta-sans-latin.woff2 | Plus Jakarta Sans | 400–800 | teks badan (`--f-body`), di-preload |
| reem-kufi-arabic.woff2, reem-kufi-latin.woff2 | Reem Kufi | 500–700 | judul Arab (`--f-ar-display`) |
| noto-naskh-arabic-arabic.woff2, noto-naskh-arabic-latin.woff2 | Noto Naskh Arabic | 400–700 | teks Arab (`--f-ar`) |
